# About Me - 自己紹介サイト

サイト URL: https://wangchangdog.github.io/about-me/

このサイトは自分の趣味や興味のあることを紹介するために作成しました。
自分はゲームや卓球が趣味なため、それらを中心にしたコンテンツでサイトを構成させてもらいました。

# 力を入れた点

## 実装面

- **JavaScript によるインタラクティブ機能**: スライドショーや背景切り替え、フォームバリデーションなど、JavaScript で多彩な機能を実装しました。
- **レスポンシブ対応**: 全ページでモバイルからデスクトップまで対応したレスポンシブデザインを実装しました。
- **パフォーマンス最適化**: 画像の遅延読み込み（lazy loading）やフォントの最適化、CSS/JS の効率化を行いました。
- **アクセシビリティ**: aria-label や alt 属性の適切な設定、キーボードナビゲーション対応など、Web 標準に準拠した実装を心がけました。
- **SEO 対策**: 各ページに適切な meta description と title タグを設定して、検索エンジン最適化を実施しました。

## デザイン面

- **League of Legends の世界観表現**: 公式ゲームの配色（金色#c8aa6e）とダークテーマを採用して、ゲームの世界観を忠実に再現しました。
- **一貫したビジュアルアイデンティティ**: 全ページで統一されたカラーパレットやフォント、レイアウトを使用して、デザインに一貫性
　　　　　　　　　　　　　　　　　　　 を持たせて見やすくしました。
- **動的な視覚効果**: 背景画像・動画の自動切り替え、ホバーエフェクト、アニメーションを適切に配置して静的なサイトに動きとインパクトを与えました。
- **情報設計**: ゲームごとやキャラクターごとに情報を整理して、ユーザーが求める情報にたどり着きやすい構造設計を行いました。
また、そのページから直前のページに戻れる様にボタンも設置し、いきたいページにたどりつきやすいようにしました。
- **モダン UI/UX**: グラデーションやボックスシャドウ、トランジション効果をAIに調整されながら作成し、視覚的に意識に残るページにしました。
- **画像選定とレイアウト**: 各キャラクター・ゲームの魅力が伝わる高品質な画像を選定して、スライドショーとかグリッドレイアウトで効果的に配置させていただきました
